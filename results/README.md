# Results directory

Commit only small, final figures and summary metrics that support the README.

Recommended files:

- `loss_curve.png`
- `accuracy_curve.png`
- `roc_curve.png`
- `precision_recall_curve.png`
- `confusion_matrix.png`
- `metrics.json`

Large checkpoints and generated datasets should remain under `outputs/`, which is excluded from Git.
